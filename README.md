# RememberThis
Remember This is a private photo album for friends and family. Add a photo, invite the people who were there, and leave a few words or a voice note about what happened. Everyone can add their side of the story to the same picture.

Voice notes are transcribed so you can find a memory even if you’ve forgotten when it happened. Search for “last train” and you can pull up the station photo, press play, and hear your friend explain how you all ended up there.
